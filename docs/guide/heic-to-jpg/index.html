아이폰 HEIC 사진을 JPG로 바꾸기

사진을 첨부하려는데 HEIC 형식을 받지 않는 곳에서 유용해요. 홈페이지의 ‘JPG 변환’에 사진을 넣으면 브라우저에서 변환하고 결과를 받을 수 있어요.

마지막 확인: 2026년 11월 15일

HEIC 파일을 준비하고 변환해요

  1. 변환하려는 사진 파일의 확장자가 .heic 또는 .heif인지 확인해요.
  2. 홈페이지의 ‘JPG 변환’ 칸에 사진을 놓거나, 칸을 눌러 파일을 선택해요.
  3. 완료 후 각 결과의 ‘받기’를 눌러요. 여러 결과는 ‘모두 ZIP으로 받기’로 묶을 수 있어요.
  4. 받은 JPG를 열어 방향, 색감, 필요한 사진 영역이 맞는지 확인해요.

원본 HEIC는 그대로 남아요. 앱이나 웹사이트가 파일 선택 창에서 HEIC를 보여주지 않으면, 먼저 원본 사진을 파일로 내보낸 뒤 선택해 보세요.

JPG가 더 작아지나요?

형식 변환은 파일 크기를 줄이는 작업과 같지 않아요. HEIC는 용량 효율이 높은 형식이라 JPG로 바꾼 결과가 오히려 커질 수 있어요. 제출 용량이 정해져 있다면 변환한 JPG를 ‘이미지 압축’에서 다시 처리하고 결과 크기를 확인하세요.

JPG는 손실 압축을 사용하는 형식이에요. 원본과 같은 픽셀 수로 저장하더라도, 파일의 바이트나 화질이 원본과 완전히 같다는 의미는 아니에요. 중요한 원본은 별도로 보관하는 것이 좋아요.

투명 배경이나 사진의 추가 정보가 중요하다면

JPG는 투명 배경을 저장하지 못해요. 투명한 이미지를 JPG로 바꾸면 투명한 부분이 흰색 배경으로 채워져요. 투명도가 필요하면 ‘PNG 변환’을 선택하세요. PNG 변환은 기존 투명도를 유지할 수 있지만, 사진 배경을 새로 지워주는 기능은 아니에요.

사진의 날짜·위치 정보, 색감이나 기기 고유 기능의 보존이 중요하다면 원본과 결과를 직접 비교하세요. 이 웹 도구는 정지 이미지 변환을 위한 기능으로, Live Photo의 동영상이나 앨범 전체를 옮기는 도구가 아니에요.

변환하지 못할 때 확인할 것

HEIC·HEIF 파일은 인코딩 방식이나 브라우저 환경에 따라 처리되지 않을 수 있어요. 파일이 정상적으로 열리는 원본인지, 확장자만 바뀐 파일이 아닌지 먼저 확인하세요.

이미지 한 장은 1,600만 픽셀까지 처리해요. 예를 들어 4,000×3,000 이미지는 1,200만 픽셀이지만, 8,064×6,048 이미지는 약 4,877만 픽셀이므로 웹 한도를 넘어요. 한도를 넘는 고해상도 사진은 더 작은 사본으로 내보낸 뒤 처리하세요.

지원 범위 안에서도 기기의 메모리가 부족하면 실패할 수 있어요. 여러 파일을 한 번에 넣었다면 적은 개수로 나눠 시도하고, 문제가 계속되면 오류 문구와 사용 환경을 문의해 주세요.
