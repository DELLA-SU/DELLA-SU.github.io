여러 이미지를 하나의 PDF로 만들기

영수증이나 신청서 사진을 하나의 문서로 묶을 때 사용해요. 이미지 한 장이 PDF 한 페이지가 되고, 선택한 순서대로 저장돼요.

마지막 확인: 2026년 11월 15일

세 장의 영수증을 한 문서로 묶는 예

receipt-1.jpg, receipt-2.jpg, receipt-3.jpg를 준비하고 홈페이지의 ‘PDF 만들기’ 칸에 함께 넣으세요. 파일 이름이나 선택 순서만 믿기보다, 실행 전에 나타나는 목록에서 실제 순서를 확인하는 것이 좋아요.

  1. ‘PDF 만들기’를 누르고 이미지를 여러 개 선택하거나, 해당 칸에 함께 드롭해요.
  2. 순서 확인 창의 위·아래 화살표로 첫 페이지부터 정렬해요.
  3. 목록을 확인한 뒤 실행하고, 완료되면 결과 옆의 ‘받기’를 눌러요.
  4. 내려받은 PDF를 열어 페이지 수, 방향, 잘린 부분이 없는지 확인해요.

이 예에서는 세 이미지를 넣으면 세 페이지의 PDF 한 개가 만들어져요. 원본 이미지 파일은 변경하지 않아요.

페이지 크기는 어떻게 정해지나요?

현재 웹 도구는 이미지의 가로·세로 비율을 이용해 PDF 페이지를 만들어요. 크기가 다른 이미지를 섞으면 PDF 안의 페이지 크기도 달라질 수 있어요. A4 규격으로 통일하거나 여백을 직접 지정하는 옵션은 제공하지 않아요.

제출처가 A4 한 장, 특정 여백이나 파일 용량을 요구한다면 결과를 먼저 확인하세요. 이미지를 PDF로 묶는 일과 인쇄 규격에 맞춰 편집하는 일은 다른 작업이에요.

사진 속 글자를 검색할 수도 있나요?

이 기능은 사진을 페이지에 배치해요. 사진 속 글자를 텍스트로 인식하는 OCR은 하지 않으므로, 문서를 PDF로 만들었다고 해서 글자 선택이나 검색이 가능해지는 것은 아니에요.

이미 텍스트가 들어 있는 PDF들을 합치려면 ‘PDF 합치기’를 이용하세요. PDF를 이미지로 바꾼 뒤 다시 PDF로 만드는 방식은 원래의 텍스트와 링크 기능을 유지하지 못해요.

사진 방향과 제출 파일을 확인하세요

파일 선택 전에 사진이 바른 방향인지 확인하고, 결과 PDF에서도 페이지별로 확인해 주세요. 개인정보가 담긴 영수증이나 신청서는 필요한 부분만 포함하는 편이 좋아요. Dropi는 변환할 파일의 내용과 이름을 서버에 업로드하지 않지만, 사용자가 내려받고 공유한 결과 파일은 직접 관리해야 해요.

사진이 많거나 이미지 한 장이 너무 크면 브라우저 메모리 한도에 걸릴 수 있어요. 웹의 입력 한도는 파일당 100MB, 한 번에 총 200MB·100개이며 이미지 한 장은 1,600만 픽셀까지예요. 한도를 넘으면 사본의 크기를 줄이거나 작업을 나누세요.
