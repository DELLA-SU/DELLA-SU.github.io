# 온라인 옷장 — AI 피팅 실험판

웹 화면은 [GitHub Pages](https://della-su.github.io/)에서 볼 수 있습니다. 옷 사진을 캐릭터에 자연스럽게 입히는 계산은 이 Mac의 로컬 AI 모델에서 실행합니다.

## 이 Mac에서 시험하기

1. `start-tryon.command`를 실행합니다. 터미널 창을 켜 둡니다.
2. 브라우저에서 `http://127.0.0.1:4319/`를 엽니다.
3. 옷 사진을 추가하고 옷장 카드를 눌러 피팅합니다. Mac에서는 결과 생성에 몇 분이 걸릴 수 있습니다.

옷 사진과 생성 결과는 브라우저의 저장소에 보관됩니다. 이미지 파일은 AI 처리 중 로컬 서버 메모리에서만 사용하고 외부 AI API로 보내지 않습니다. 다른 기기와 동기화하는 기능은 아직 없습니다.

AI 합성은 기존 캐릭터 사진과 옷 사진을 입력으로 받아 새 착용 이미지를 생성합니다. 캐릭터와 옷의 원본은 별도 자산으로 보관하지만 생성된 결과는 한 장의 이미지입니다. 리본, 지퍼, 로고 등 원본 옷의 세부 형태가 바뀔 수 있으므로 실제 핏이나 상품의 정확한 모습으로 판단하면 안 됩니다. 현재 상의·아우터·하의 한 벌씩 시험할 수 있고 신발·소품은 지원하지 않습니다.

로컬 모델: [FASHN VTON v1.5](https://github.com/fashn-AI/fashn-vton-1.5). 모델 파일은 `work/tryon-research/fashn-vton-1.5/weights`에 있어야 합니다.
