# 온라인 옷장 — AI 피팅 실험판

웹 화면은 [GitHub Pages](https://della-su.github.io/)에서 볼 수 있습니다. 옷 사진을 캐릭터에 입히는 계산은 이 Mac의 로컬 AI 모델에서 실행합니다. GitHub Pages와 `file://` 화면에서는 피팅 연결이 차단될 수 있으므로 아래 로컬 주소를 사용합니다.

## 이 Mac에서 시험하기

1. `start-tryon.command`를 실행합니다. 터미널 창을 켜 둡니다.
2. 브라우저에서 `http://127.0.0.1:4319/`를 엽니다.
3. 옷 사진을 추가하고 옷장 카드를 눌러 피팅합니다. 실제 갈색 재킷 시험에서는 생성에 약 13분이 걸렸습니다.

옷을 추가할 때 사진 촬영 방식을 선택합니다. 옷만 놓고 찍은 사진이나 상품 이미지는 **옷만 찍은 사진**, 사람이 이미 입고 있는 이미지는 **사람이 옷을 입은 사진**을 고릅니다. 로컬 모델은 후자의 경우 사진 속 사람을 분리하고 해당 옷을 참고하도록 처리합니다. 결과가 마음에 들지 않으면 왼쪽의 **⟳ 다시 입혀보기**로 다른 생성 결과를 시험할 수 있습니다. 한 번에 한 벌씩 처리하므로 새 옷을 입히면 이전 합성 결과를 바탕으로 누적하지는 않습니다.

옷 사진과 생성 결과는 브라우저의 저장소에 보관됩니다. 이미지 파일은 AI 처리 중 로컬 서버 메모리에서만 사용하고 외부 AI API로 보내지 않습니다. 다른 기기와 동기화하는 기능은 아직 없습니다.

AI 합성은 기존 캐릭터 사진과 옷 사진을 입력으로 받아 새 착용 이미지를 생성합니다. 캐릭터와 옷의 원본은 별도 자산으로 보관하지만 생성된 결과는 한 장의 이미지입니다. 리본, 지퍼, 로고 등 원본 옷의 세부 형태가 바뀔 수 있으므로 실제 핏이나 상품의 정확한 모습으로 판단하면 안 됩니다. 현재 상의·아우터·하의 한 벌씩 시험할 수 있고 신발·소품은 지원하지 않습니다.

로컬 모델: [FASHN VTON v1.5](https://github.com/fashn-AI/fashn-vton-1.5). 모델 파일은 `work/tryon-research/fashn-vton-1.5/weights`에 있어야 합니다.

## 기술 검토 기록

- FASHN VTON v1.5는 옷만 찍은 사진과 착용 사진을 모두 입력받는 공개 모델이라 현재 Mac에서 로컬 실행합니다. 같은 갈색 재킷에 대해 30단계와 50단계를 비교했지만 50단계에서도 리본과 지퍼가 복원되지 않았습니다. 따라서 느린 50단계 설정은 웹사이트에 적용하지 않았습니다. 30단계에서 생성값을 바꾼 시험에서는 회색 리본과 중앙 여밈이 일부 나타났지만 형태가 원본과 달랐습니다. **다시 입혀보기**는 결과 후보를 바꾸는 기능이며 정확한 옷 재현을 보장하지 않습니다.
- [CatVTON](https://github.com/Zheng-Chong/CatVTON)은 1024×768 추론과 마스킹 도구를 제공하지만 공개 실행 절차가 CUDA 기반이고 라이선스가 비상업용 CC BY-NC-SA 4.0이라 현재 Mac의 배포 모델로 연결하지 않았습니다.
- [Oxygen-TryOn](https://github.com/oxygenVision/Oxygen-TryOn)은 세부 요소 보존을 목표로 하지만 공개 저장소에 추론 코드와 가중치가 아직 없어 로컬 설치가 불가능합니다.
