해상도와 목표 용량을 정해 이미지·PDF 압축하기

‘해상도 유지’와 ‘화질 유지’는 같은 뜻이 아니에요. 제출 용량에 맞추려면 어떤 정보를 보존할지 먼저 정하고, 결과 파일 크기와 내용을 함께 확인하는 것이 좋아요.

마지막 확인: 2026년 11월 15일

픽셀 수, 화질, 파일 크기는 달라요

해상도 유지를 켜면 이미지의 가로·세로 픽셀 수를 유지해요. JPG는 같은 픽셀 수에서도 재압축 품질에 따라 선명도와 용량이 달라질 수 있어요. 중요한 작은 글자나 선이 있다면 확대해서 원본과 비교해 주세요.

목표 용량을 비워두면 ‘화질 우선·균형·용량 우선’ 중에서 선택해요. JPG 기준으로 화질 우선은 높은 품질을, 용량 우선은 더 작은 파일을 목표로 해요. 모든 파일 형식에 같은 비율의 압축이 적용되는 것은 아니에요.

사진을 파일당 5MB 이하로 보내고 싶다면

  1. ‘용량 압축’ 탭에서 ‘파일당 목표’에 5를 입력하고 MB를 선택해요.
  2. 원본 픽셀 수가 필요하면 해상도 유지를 켜요.
  3. ‘이미지 압축’ 칸에 파일을 넣어요. 목표를 입력하면 수준 선택 대신 목표에 맞춰 자동 조절해요.
  4. 결과의 파일 크기와 ‘목표 초과’ 표시를 확인하고, 내려받은 사진의 화질을 확인해요.

목표는 파일 하나마다 적용돼요. 사진 3장에 5MB를 입력한다고 세 장의 합계가 5MB가 되는 것은 아니에요. JPG는 품질을 조절해 목표에 접근하지만, 해상도 유지 조건에서 목표 달성이 어려운 파일도 있어요.

원하는 용량을 맞추지 못하면 더 작은 사본을 준비하거나 해상도 유지 옵션을 끄는 방법을 고려할 수 있어요. 그 경우에는 픽셀 수가 줄어들 수 있으니 결과 확인이 필요해요.

투명 PNG와 PDF는 어떻게 다른가요?

투명 PNG는 투명도를 유지하는 방식으로 처리해요. JPG처럼 품질을 계속 낮춰 어떤 목표 용량이든 맞추는 방식은 아니에요. 이미 최적화된 이미지라면 거의 줄지 않거나 원본 크기로 저장될 수 있어요.

PDF에서 구조 유지를 켜면 문서 구조를 유지하며 다시 저장해 최적화해요. 웹의 이 방식은 PDF 안의 이미지를 직접 재압축하지 않으므로, 사진이 많은 PDF도 감소 폭이 작을 수 있어요. PDF 목표 용량은 달성을 보장하지 않아요.

구조 유지를 끄면 각 페이지를 이미지로 만들어 PDF에 저장해요. 이 경우 텍스트 선택·검색, 링크·양식 기능이 사라져요. 문서 속 글자를 복사하거나 링크를 눌러야 하는 용도라면 구조 유지 옵션을 켜고 결과를 확인하세요.

압축 전후에 확인할 것

처리된 결과가 원본보다 크면 원본 크기로 제공될 수 있어요. 파일이 더 줄지 않았다는 사실이 항상 오류를 뜻하는 것은 아니에요. 작은 파일, 이미 손실 압축이 강하게 적용된 사진, 최적화된 PDF는 추가로 줄이기 어려워요.

제출할 때는 파일 크기뿐 아니라 이미지 방향·투명도·작은 글자, PDF 페이지 수와 필요한 문서 기능도 확인하세요. 원본은 별도로 보관하고, 외부 공유 전에 개인 정보가 포함되어 있지 않은지 직접 확인해 주세요.
