# 내일의 옷장

공개 주소: https://della-su.github.io/

내 전신 사진과 옷 사진으로 다음 날의 코디를 시험하는 온라인 옷장 시제품입니다. 새 아바타를 생성하는 기능은 제거했습니다. 화면의 기준 인물은 사용자가 직접 올린 정면 전신 사진입니다.

## 현재 화면

1. 첫 방문에 키, 몸무게, 옷장 이름과 정면 전신 사진을 등록합니다. 측면·뒷면 사진은 별도로 볼 수 있습니다.
2. 옷 사진을 상의·하의·원피스·신발·소품으로 등록하고 고릅니다.
3. **실사 입혀보기**에서 선택한 옷 한 벌을 전신 사진에 합성합니다. 이미 합성한 결과에 다음 옷을 이어 입힐 수도 있습니다. 여러 번 생성하면 얼굴·옷 디테일이 달라질 수 있습니다.
4. 결과를 보고 코디 앨범에 저장하거나 달력 날짜에 배치합니다.

옷장 데이터는 현재 브라우저의 IndexedDB에 저장됩니다. 자동 기기 동기화는 아직 구현되지 않았으며 JSON 백업 내보내기·가져오기를 제공합니다. 예시 인물 이미지는 배포 파일에서 제거했습니다. 업로드한 사진은 **설정 → 저장된 사진 모두 삭제**에서 이 브라우저의 전신·얼굴·옷·합성 사진과 코디·달력 계획을 삭제할 수 있습니다. 옷장 이름, 키, 몸무게는 유지됩니다. 다른 기기의 브라우저 저장소는 그 기기에서 따로 삭제해야 합니다.

## 옷 합성 방식

- **무료 로컬:** [FASHN VTON v1.5 공개 모델](https://github.com/fashn-AI/fashn-vton-1.5)을 이 컴퓨터에서 실행합니다. API 크레딧은 들지 않습니다. 옷 사진 형태(옷만 찍은 사진/사람이 입은 사진)와 20·30·50단계를 고를 수 있습니다. 이전 테스트의 인물 사진과 결과 파일은 삭제했습니다. 사용자의 옷에서 원하는 품질이 나오는지는 아직 검증되지 않았습니다.
- **FASHN 유료 API:** 별도 API 키와 크레딧을 설정하면 Try-On Max로 옷 한 벌을 합성합니다. 전신 사진·옷 사진을 외부 서버로 보내는 동의를 화면에서 받은 뒤에만 요청합니다. 실사용 품질은 아직 검증하지 않았습니다.

AI가 만드는 결과는 사진상의 **예상 모습**입니다. 원본 옷의 정확한 cm 치수, 착용감, 로고·문자·무늬·주름을 보장하지 않습니다. 신발·소품은 현재 선택 목록과 저장 카드에는 들어가지만 AI 합성 입력은 상의·하의·원피스 한 벌씩만 지원합니다.

## 로컬 실행

현재 작업 폴더에서 모델 환경과 가중치가 준비된 상태라면 다음 명령으로 무료 합성을 시험할 수 있습니다.

```sh
cd outputs/website
PYTORCH_ENABLE_MPS_FALLBACK=1 ../../work/tryon-research/.venv/bin/python local_tryon_server.py \
  --weights-dir ../../work/tryon-research/fashn-vton-1.5/weights \
  --port 4330
```

그다음 `http://127.0.0.1:4330/`에서 사용합니다. 이 맥에서는 기존 정적 미리보기 서버가 4319 포트를 사용 중이라 4330을 택했습니다. 서버는 `127.0.0.1`에만 연결됩니다. [GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages)는 정적 호스팅이므로 공개 주소에서는 AI 합성을 직접 실행할 수 없습니다. 유료 API 키를 HTML·JavaScript·Git에 넣지 마세요.
