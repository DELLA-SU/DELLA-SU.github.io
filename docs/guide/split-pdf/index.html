긴 PDF를 원하는 개수나 페이지 수로 나누기

PDF를 넣으면 전체 페이지 수를 확인하고 나누는 방식을 선택할 수 있어요. 실행 전에 표시되는 페이지 범위를 확인하면 원하는 결과를 만들기 쉬워요.

마지막 확인: 2026년 11월 15일

세 가지 방식의 차이

10페이지 PDF를 나누는 예
방식입력 예만들어지는 결과
파일 개수3개1~4 / 5~7 / 8~10페이지
파일당 페이지 수4페이지씩1~4 / 5~8 / 9~10페이지
한 페이지씩별도 숫자 없음각각 1페이지인 PDF 10개

‘파일 개수’는 원래 순서를 유지하며 최대한 고르게 나눠요. 페이지 수가 딱 나누어떨어지지 않으면 앞쪽 결과에 한 페이지씩 더 들어가요. 이 설정은 파일 용량을 똑같이 나누는 기능이 아니에요.

실행하고 결과를 받는 순서

  1. 홈페이지의 ‘PDF 나누기’ 칸에 PDF를 넣어요.
  2. 페이지 수 확인이 끝나면 나누는 방식과 숫자를 정해요.
  3. 미리보기 목록에서 각 결과에 들어갈 시작·끝 페이지를 확인해요.
  4. ‘PDF로 나누기’ 버튼을 눌러 실행해요.
  5. 결과를 개별 PDF로 받거나 ‘모두 ZIP으로 받기’로 한 번에 저장해요.

200페이지를 7개 파일로 나누면 앞의 4개는 29페이지씩, 뒤의 3개는 28페이지씩이에요. ‘파일당 60페이지’를 선택하면 60·60·60·20페이지인 네 파일이 만들어져요.

페이지 범위와 저장을 확인하세요

분할은 원본의 페이지 순서와 페이지 크기·회전을 유지하는 방식으로 처리해요. 결과 이름에는 페이지 범위가 포함되어 구분할 수 있어요. 원본 파일은 바꾸지 않아요.

특정 페이지만 골라 삭제하거나, 1~3페이지와 8~10페이지를 하나의 결과로 묶는 사용자 지정 범위 편집은 현재 제공하지 않아요. 분할 전에 원하는 개수와 연속된 페이지 범위가 맞는지 확인하세요.

작업 완료 문구가 나와도 브라우저가 파일을 자동으로 저장하는 것은 아니에요. 결과의 ‘받기’ 또는 ZIP 버튼을 눌러야 해요. 페이지를 닫기 전에 다운로드를 마치고, 저장한 파일이 열리는지 확인해 주세요.

나눠지지 않는 경우

1페이지 PDF는 더 나눌 수 없어요. 파일 개수는 2개부터 원본 페이지 수까지, 파일당 페이지 수는 원본보다 작은 양의 정수로 입력하세요. 웹은 PDF 한 파일당 200페이지, 결과는 한 번에 총 300개까지 처리해요.

암호로 잠긴 PDF는 먼저 잠금이 해제된 사본이 필요해요. 양식·전자서명 등 중요한 문서 기능은 분할 뒤에도 원래 상태로 유지된다고 보장하지 않아요. 원본을 보관하고 제출 전에 결과를 확인하세요.
